# M5N-D — Bubble Translation Only

M5N-D changes the live Social Translate floating bubble so the bubble shows translation text only.

Changed:
- removed Cidentia header text from the floating bubble body
- removed safety/status text from the bubble body
- native live OCR text is filtered before being pushed to the bubble
- basic local Turkish translation mapping runs before bubble update
- duplicate bubble updates are skipped

Still locked:
- no automatic WhatsApp sending
- no Accessibility automation
- no hidden WhatsApp reading
- no backend upload
- no account/login control

Note:
This is still a local/offline preview translator. A stronger translation engine remains the next product step.
